Reads a data file that refreshes itself on a schedule. This is the safe option — your SeaTable token lives in GitHub's encrypted secrets and never reaches anyone's browser.

Read this first. Your token is used only by your own browser and is never written into the website's code or uploaded to GitHub. But anyone who uses this computer could recover a remembered token — so use a read-only token, and leave "Remember" off on shared machines. If your browser blocks the request, SeaTable isn't allowing direct browser access; use the scheduled snapshot instead.
